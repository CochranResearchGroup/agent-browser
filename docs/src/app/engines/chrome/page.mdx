# Chrome

Chrome (and Chromium) is the default browser engine. agent-browser discovers, launches, and manages the Chrome process automatically via the Chrome DevTools Protocol (CDP).

## Binary Discovery

Agent Browser uses installed Stock Google Chrome or a configured Chromium StealthCDP build. The default executable discovery checks Stock Chrome in the following locations.

<table>
  <thead>
    <tr><th>Platform</th><th>Locations checked</th></tr>
  </thead>
  <tbody>
    <tr><td>macOS</td><td><code>/Applications/Google Chrome.app</code></td></tr>
    <tr><td>Linux</td><td><code>google-chrome</code> and <code>google-chrome-stable</code> in PATH</td></tr>
    <tr><td>Windows</td><td>Google Chrome under Local AppData or Program Files</td></tr>
  </tbody>
</table>

Install Stock Google Chrome through your operating system or configure the Chromium StealthCDP build manifest. Agent Browser does not install or launch Chrome for Testing. A legacy executable pin that points to it must be replaced with an approved build. Check profile compatibility before relaunching with an older major version.

## Usage

Chrome is the default engine -- no `--engine` flag is needed:

```bash
agent-browser open example.com
```

To be explicit:

```bash
agent-browser --engine chrome open example.com
```

## Custom Binary

Point to your installed Stock Chrome or Chromium StealthCDP executable with `--executable-path`:

```bash
agent-browser --executable-path /path/to/chromium-stealthcdp open example.com
```

Or via environment variable:

```bash
export AGENT_BROWSER_EXECUTABLE_PATH=/path/to/chromium-stealthcdp
agent-browser open example.com
```

## Containers and CI

In Docker, CI runners, or other sandboxed environments, Chrome's user namespace sandbox may need to be disabled:

```bash
agent-browser --args "--no-sandbox" open example.com
```

agent-browser automatically adds `--no-sandbox` when it detects a container environment (Docker, Podman, running as root).
