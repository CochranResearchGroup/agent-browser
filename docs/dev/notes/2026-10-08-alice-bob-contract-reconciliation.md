## Decision provenance

The operator explicitly retired legacy RDP/root-helper prerequisites and selected native Remote View in the supplied conversation. The operator also requested up to ten desktops. These are actual user instructions. Current policy D confirms the ownership boundary. C explicitly retains or adapts presentation-neutral invariants rather than discarding them wholesale.

PRs 210 and 211 record a governing workflow contract and narrower acceptance gates. Their inspected bodies and issue 209 contain agent-authored approval assertions, but no quoted user decision cancelling overflow sharing, queueing, named handoff longevity, or reference-aware shrink. Narrower acceptance is not evidence of cancellation. The located original-thread rollout is a continuation and did not expose the cited full grilling segment in the bounded user-message inspection; A and B are preserved specification evidence, not a claim that every original user answer was independently recovered. Graphiti supplied advisory leads, not additional approval provenance.

Therefore these differences remain decision-unresolved. This note does not silently reinstate all historical architecture or numeric defaults. In particular, historical six-display and density-four values were provisional; ten configured total desktops includes a direct-use desktop and does not prove ten Agent Browser slots or ten-browser stress acceptance.

## Material findings

1. Native ownership legitimately supersedes Agent Browser-owned XRDP users, Guacamole inventory, credential custody and root-helper installation. Those mechanisms should stay retired.
2. Separate placement now has bounded installed proof: five simultaneous synthetic browsers on distinct desktops and ready native handoffs. This does not establish overflow sharing, a prioritized bounded queue, or ten-browser stress.
3. Current documented logical handoffs expire after 24 hours, including retained named work unless explicitly extended before expiry. This is separate from viewer authentication and idle cleanup. G36 requested named handoffs without a default time expiry. The mismatch is real; cancellation provenance was not established.
4. G43/G44 same-profile Alice/Bob isolation needs current paired qualification. Independent-profile placement is insufficient proof.
5. G05/G23 availability needs a targeted counterexample: an unrelated stale or unresolved assignment versus a currently unsafe exact resource. Protecting an exact resource from destructive cleanup is legitimate; treating unrelated history as a blanket launch veto is not the same thing.
6. Reference-aware automatic shrink remains unqualified by P226. Historical cooldown and warm-target numbers should not be silently imposed on native provider policy.
