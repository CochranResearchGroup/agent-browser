## Workflow outcome

An app can explicitly disconnect and reconnect the same task without resuming human-paused automation. Report-only is the default loss policy. Opted-in reopen requires positive original-process absence, explicit exact current app placement, original profile/custody admission and a durable request; unknown effects remain pending. Live physical relocation is unsupported. Borrowed reopening requires fresh trusted attachment, never an app-browser relaunch.

Optional app defaults and task replacements gate supported MCP, CLI and service dispatch. Exact operator overrides retain task/action/request identity. Authorized local artifact handles do not publish results. Scoped detach preserves borrowed browsers and peers. Broader managed close requires fresh process readback and refuses unknown process epochs. Task policies/grants retire with their task. Versioned guidance keeps Bots-native work and Agent Browser task work within their respective ownership.
