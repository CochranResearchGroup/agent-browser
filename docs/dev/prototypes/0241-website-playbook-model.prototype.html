    Develop and adapt a SiteGuide

    A SiteGuide recognizes states and states what success means. A routine performs one reusable subtask. A playbook chooses the next routine; a skill guides an agent through the same choices. In this model, guide revision 1 recognizes the initial page variant. A changed control requires a fresh observation and a new guide revision before the playbook can prepare another routine.

    For a real guide: capture synthetic examples, define recognizable states and exact-account success, implement a small routine, exercise changes and uncertain outcomes, then document how an agent adapts. Guide revision here is a simulation; automatically saving or publishing an unreviewed site change is not a settled product behavior.

    Provider boundary: Remote View supplies desktop effects. The shared auth helper supplies private credential/MFA operations. Agent Browser interprets website state and preserves task progress. This prototype simulates the boundaries; it does not prove those integrations.
