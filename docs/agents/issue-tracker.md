# Issue tracker: GitHub

Work is tracked in CochranResearchGroup/agent-browser GitHub Issues. Use gh with this explicit repository; never publish ordinary work against vercel-labs/agent-browser. Numbered repo plans define bounded delivery; ROADMAP defines direction and RUNBOOK records execution. They supplement the tracker rather than replacing it.

Read full issue bodies, comments, labels and current source before disposition. Use body files for multiline comments. Every triage comment begins with `> *This was generated by AI during triage.*`. Preserve historical reports; append current findings and evidence. A closed superseded issue does not prove its historical reproduction now passes.

PRs as a request surface: no. Explicitly named PRs may still be reviewed. Source changes land through a PR linked to their work item. Issue review does not authorize production, provider, authentication or cleanup effects.

For native issue dependencies, use GitHub issue database IDs for blocking edges. Never treat an old plan's OPEN state as current execution authority.
