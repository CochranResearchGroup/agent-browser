# Triage labels

The operator-approved canonical mappings are:

| Role | Tracker label |
| --- | --- |
| bug | bug |
| enhancement | enhancement |
| needs-triage | needs-triage |
| needs-info | needs-info |
| ready-for-agent | ready-for-agent |
| ready-for-human | ready-for-human |
| wontfix | wontfix |

Every reviewed issue carries exactly one category and one triage state role. Existing state/ready and state/triage are migrated for reviewed issues. state/blocked and state/in-progress are separate coordination metadata; they do not authorize work or substitute for triage qualification. Never infer reporter inactivity is a current failure. If canonical triage state roles conflict, report the conflict before changing the issue.
